## Overview

Wavelet is the official companion application for the **Wavelet Smart Speaker** series.

It provides a seamless setup experience, device management, firmware updates, music control, and future smart-home integrations through a clean and modern interface.

The app is built entirely with Flutter, allowing the same experience across Android, iOS, Windows, macOS and Linux.

> The goal is simple:
>
> Smart speakers should be easy to set up, enjoyable to use, and beautiful to look at.

## Features

### Device Pairing

- QR Code onboarding
- BLE discovery
- Wi-Fi provisioning
- Secure pairing tokens

## 🎨 Design

Wavelet follows a minimal, card-based interface inspired by modern operating systems and streaming platforms.

The design language focuses on:

- Soft animations
- Rounded components
- Accessibility
- Material Design 3
- Simple navigation
